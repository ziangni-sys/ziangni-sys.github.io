# ziangni-sys.github.io

Ziang Ni 的学术主页，纯静态 HTML/CSS，无需构建，GitHub Pages 直接托管。页面不加载任何脚本来画图：背景的两种纹样是 `assets/style.css` 里的两个 SVG 单元（data URL），由 `body::before` 和 `body::after` 两个伪元素铺在整页底下，`index.html` 里没有任何装饰用的元素。纹样单元由 `scripts/ground.js` 生成（只在改纹样时运行一次，网页本身不需要它）。

## 文件

- `index.html`: 全部内容（首页标题、About、News、Publications、Projects、联系方式）
- `assets/style.css`: 样式、配色和背景纹样。颜色都是 `:root` 里的变量，深色模式的取值紧跟其后（`prefers-color-scheme` 和 `data-theme="dark"` 两处，改色时两处都要改）
- `assets/favicon.svg`: 网站图标（藏青底上的「真木柱」）
- `assets/akanezora.svg`: Akanezora Capital 的标志（原图去掉了四周的留白），在 About 最后一段公司名前当作小印章显示
- `scripts/ground.js`: 生成两个纹样单元（矢絣、青海波）的脚本（Node，无依赖）。运行 `node scripts/ground.js`，它只改写 `assets/style.css` 里 `/* gen:tiles */` 与 `/* /gen:tiles */` 之间的四行变量，标记以外的部分不动；运行两次结果相同。它还会核对页眉的家纹、About 列表的三个符号和 favicon 是否仍与渲染器画出的一致，不一致就报错退出
- `tools/genji/`: 核对过的源氏香数据集和渲染器（见该目录的 README）
- `assets/ziang_ni_cv.pdf`: 网页上链接的 CV，由 LaTeX 源文件编译而成，只是页眉里去掉了电话号码。更新 CV 时直接用新 PDF 覆盖这个文件（文件名不变，页面上的链接就不用改）

## 版式

整体是「纹样帖」那一版的风格：和纸底色、EB Garamond 正文与 Cormorant Garamond 标题、藏青一色加一点朱红（只在链接悬停和键盘焦点上出现）、各节前的壹貳參肆、左侧联系方式加右侧正文的两栏。

纹样不是放在页面上的图，而是染在纸里的底：

- **页首**：藤色的矢絣从右上方染进来，最浓的一团在首页右半边的空白里（名字的右边），从纸的右边缘往左、往下晕开（ぼかし）。沿上边缘从右上角到页面中间只有几片很淡的浅染，深浅不一，所以导航和昼/夜按钮压在几乎看不出的淡处，导航仍是「纹样帖」那一版的灰色；左上的家纹和名字都站在素纸上。
- **中间**：页首和页尾之间，两种纹样交替从左右两边晕进来：青海波从左（侧栏一带，约页面高度 22% 处）、矢絣从右（约 40%）、青海波再从左偏中（约 59%，垫在正文下面）、矢絣再从右（约 77%）。一左一右错开，两种纹样只在交界处淡淡地融在一起；加上页首和页尾，大约四分之三的纸面有纹样（浅色模式下桌面约 80%、手机约 72%、超宽屏约 64%）。压在文字下面的地方染得很淡，保证每一行字的对比度（见下面）。
- **页尾**：淡青色的青海波从纸的下边缘升起来，左边升得最高（垫在侧栏下面的空白里），往右只有两片贴着下边缘的低浅晕染，中间留着素纸，所以不会成为一道沿着页脚的整齐色带。页脚的版权一行靠右，放在素纸上，和页首「名字在左、矢絣在右」正好对角呼应。
- 没有边框、没有色块、没有分界线，所以看起来是一张染过的纸，而不是一块块贴上去的图。
- 纹样只作装饰，页面上不加任何文字说明。伪元素没有文字内容，读屏软件不会读到它们。

### 晕染是怎么做的（都在 `assets/style.css` 的「the ground」一节）

- `body::before`（矢絣，贴着页首）和 `body::after`（青海波，贴着页尾）是两层全宽的伪元素，`z-index: -1`，在文字下面、纸色上面。
- 每层用纹样单元做 `mask`（遮罩）：单元里只有形状（矢羽、波纹的线），不带颜色，按单元大小平铺。
- 颜色来自这一层的 `background`：几个椭圆渐变（`radial-gradient`）叠在一起，每个都从染料色淡到透明。颜色淡到没有时，纹样也就跟着消失，这就是晕染。
  - 一团「深染」（pool）：中心一小段是全浓的 `--ya` / `--sg`，往外换成 `--ya-thin` / `--sg-thin`，强度按 64%、32%、11% 淡出到 0。渐变的写法存在 `:root` 的 `--ya-deep`、`--sg-deep` 里。矢絣的深染贴着右边缘，最浓处在页面往下 `--ya-pool-y` 的地方；青海波的深染在左下角。
  - 几片「浅染」（veil）：最浓也只有 36%（青海波 44%），按 20%、7% 淡出，写法存在 `--ya-thin-veil`、`--sg-thin-veil` 里。它们大小不同、沿边缘错开放（`--ya-a`、`--ya-b`、`--ya-c`、`--sg-a`、`--sg-b` 是大小，`-x` 是在边缘上的位置），所以染色的边缘是起伏的，不是一条水平线。
  - 几团「中染」（mid）：中间那四团，最浓只有 42%（青海波 44%），这个浓度保持到半径的 28% 处，再按 30%、14% 淡出，写法存在 `--ya-mid`、`--sg-mid` 里。大小是 `--sg-m1`、`--ya-m1`、`--sg-m2`、`--ya-m2`，位置是对应的 `-at`（横向位置、纵向位置；纵向用页面高度的百分比，所以页面变长时它们跟着拉开）。想让纹样更多或更少，先改这四团的大小；想更浓，改 `--ya-mid` / `--sg-mid` 里的百分比，但要重新量对比度。
  - 两层（矢絣层 `body::before`、青海波层 `body::after`）都铺满整个页面高度，各团晕染的形状完全由渐变决定。
- 这些尺寸的高度都用 rem 写，所以读者把浏览器默认字号调大时，晕染和文字一起往下移，名字仍然在素纸上。宽度用屏幕宽度的百分比，大屏上用 `min(…vw, …rem)` 封顶（`radial-gradient` 的大小里写 `min(%, rem)` 时，Chrome 会把整条 `background` 当作无效而忽略，所以用 vw）。手机（≤38.75em）在媒体查询里另给一组：矢絣的深染挪到名字右边那一小块空白（在第二行导航和名字下面那行字之间），右上角的浅染顺着右边缘接下来；青海波收窄、收矮，版权一行压在素纸上，波纹只在它下面。
- **文字的对比度**：量法是先记下每一行文字的位置，再把所有文字设为透明截一张图，取每一行文字下面最暗（深色模式下最亮）的那个像素算对比度。现在 320–1920px、浅色和深色、16px 和 20px 默认字号下，每一行文字都至少 4.7:1（最紧的是压在中染上的灰色小字，如论文摘要）。改 `--ya`、`--ya-thin`、`--ya-mid`、`--sg-mid`、各团的大小或位置、或页脚的 `padding-bottom` 时，要重新确认所有文字仍然达标（≥4.5:1）。

### 纹样单元（`scripts/ground.js` 写进 `style.css` 的 `/* gen:tiles */` 区域）

每个单元是一段 SVG，转成 `url("data:image/svg+xml,…")` 存在变量 `--yagasuri`、`--seigaiha` 里，单元大小存在 `--yagasuri-size`、`--seigaiha-size` 里。

- 矢絣 `yagasuri(20, 56, 10, 1)`：每列宽 20，是一支箭的羽毛，人字形，尖朝上，尖在列中线（箭杆，留一道宽 1 的空隙）。一列里染色的羽毛和不染的羽毛交替，一染一白合计 56；相邻一列向下错开半个纹样（28），所以染色的羽毛旁边总是不染的。人字从中线到列边落差 10。单元 40×56（两列）。
- 青海波 `seigaiha(24, 3, 1.25)`：每把扇是半径 24 的一圈加里面 3 圈同心圆（18、12、6），线宽 1.25；排距 12，相邻两排错开 24，下一排压在上一排上面。因为要用作遮罩，单元里用一个 SVG `<mask>` 来画：从上往下一排排画，每把扇先画一个黑色圆盘（遮住它后面的线），再画白色的圈。单元 48×24。
- 要改大小，就改 `scripts/ground.js` 里 `yagasuri(…)`、`seigaiha(…)` 这两行的数字，再运行一次脚本。不要直接改 `gen:tiles` 区域里的内容（下次生成会被覆盖）。

### 源氏香

源氏香只作单个的符号出现，不排成表：

- 页眉左上的 `.brand-mark`：加圈的「真木柱」（第 31 帖），像一枚家纹。
- `assets/favicon.svg`：藏青底上的真木柱。
- About 列表的三个符号是 CSS 遮罩（`.themes li::before` 里的 data URL），依次是真木柱、帚木、手習，路径是 `render(groups, {width: 13, stroke: 1})`。要换，就把 data URL 里 `d='…'` 换成别的帖用同样参数生成的路径；每个符号在 CSS 里写了两遍（带 `-webkit-` 前缀的一行和不带前缀的一行），两行都要改，并相应修改 `scripts/ground.js` 末尾的核对。
- 所有路径都由核对过的渲染器 `tools/genji/genji.js` 生成（数据集是同目录的 `genji.json`，出处与画法规则见 `tools/genji/README.md`，`python3 -B tools/genji/check.py` 可自检）。请不要手改这些路径。

### 颜色

- 染料：`--ya`（矢絣的藤色）、`--sg`（青海波的浅缥）是它们最浓处的颜色；`--ya-thin`、`--sg-thin` 是淡处用的颜色，色相更偏蓝一点、彩度更高一点，以较低的强度叠在纸上。藤色和米色的纸几乎是补色，直接混会在半淡处变成发灰的粉色；用偏蓝的淡色，淡下去的地方仍是浅藤色 / 浅青色，直到几乎看不见。深色模式下四者都是比底色稍亮的暗色（夜里的藤色、深青）。
- 切换昼/夜时整页一次换色，没有渐变。
- 浅色模式最浅的文字（`--ink-soft`）对纸色的对比度是 5.7:1，深色模式 6.8:1；压在中染上时最低约 4.7:1（浅色）和 5.7:1（深色）。改 `--paper` 或 `--ink-soft` 时不要让它低于 4.5:1，并照上面的量法再量一次压在纹样上的那几行。

## 字体

- 正文 EB Garamond，标题 Cormorant Garamond，日文 Shippori Mincho。
- Shippori Mincho 用 Google Fonts 的 `text=` 参数只下载页面实际用到的字：壹貳參肆昼夜（几 KB）。**页面上新增任何汉字/假名时，要把它加进 `index.html` 里那条字体链接的 `text=`（需 URL 编码）**，否则会退回系统字体。

## 常见修改

- **加头像**：目前头像位置留空。把照片放到 `assets/photo.jpg`，然后取消 `index.html` 侧栏里那段注释，即 `<div class="portrait"><img …></div>`（建议 4:5 竖幅，样式已在 `.portrait` 里写好）。
- **改单位/年级**：首页名字下面的 `<p class="affil">` 和 About 第一段。
- **加 Google Scholar 等链接**：在侧栏 `<ul class="contact">` 里照现有格式加一个 `<li>`。
- **加论文**：复制一个 `<li class="pub">…</li>` 块；左侧标签写 Preprint 和年份。投稿中的论文不要写会议名称（双盲审稿），网页和网页版 CV 都只写 Preprint；BibTeX 按钮的 `aria-controls` 要和 `<pre>` 的 `id` 对应。
- **加新闻**：在 `<ol class="news">` 顶部加一个 `<li>`。
- 记得同步更新页脚的 “Last updated”。
